# SatyaCheck

SatyaCheck helps people investigate suspicious messages instead of just labeling them fake or real.

## What it does
- Accepts claims in supported regional languages
- Classifies the claim with a multilingual machine-learning model
- Searches news sources for relevant coverage
- Compares the claim against the evidence retrieved
- Shows a risk assessment, supporting evidence and source links
- Uses Hindsight memory to recall previously investigated claims

## Tech stack
React, Vite, Python, Flask
